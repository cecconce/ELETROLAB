# ElettroLab

Simulatore didattico gratuito per gli istituti tecnici: impianti elettrici, PLC Ladder, Arduino ed elettronica in un unico programma per Windows.

> **Stato:** in sviluppo — Fase 0 (progettazione). L'avanzamento è descritto in [STATO.md](STATO.md).

## Moduli previsti

| Modulo | Cosa fa |
|---|---|
| Impianti elettrici | Disegno e simulazione di schemi elettromeccanici di potenza e comando (contattori, temporizzatori, motori…) |
| PLC | Programmazione Ladder con ciclo di scansione e impianti virtuali animati |
| Arduino | Breadboard con Arduino Uno, editor di codice e a blocchi, monitor seriale |
| Elettronica | Schemi analogici e digitali con simulazione SPICE e strumenti virtuali |

## Principi

- **100% offline:** nessun account, nessuna telemetria, nessuna raccolta dati.
- **Portable:** si avvia da cartella o chiavetta USB, senza permessi di amministratore.
- **Leggero:** pensato per PC con Windows 10 e 4 GB di RAM.
- **Aperto:** componenti ed esercizi in file JSON modificabili da docenti e studenti.
